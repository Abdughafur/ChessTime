# ChessTime

ChessTime is an open-source digital chess clock app for over-the-board chess games.

Built with Kotlin and Jetpack Compose for Android.

## Features

- Two-player chess timer
- Split screen for BLACK and WHITE players
- Preset times: 1, 5, 10, 15, 20 minutes
- Custom timer
- Sound and vibration feedback
- Dark mode support
- Offline-first

## Tech Stack

- Kotlin
- Jetpack Compose
- Material 3
- MVVM Architecture
- DataStore
